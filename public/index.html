2. Lifecycle definitions

Submitted: Gmail accepted the API request. Delivered: only mark with positive delivery evidence. Bounced: recognizable failure notice found. Opened: pixel requested. Clicked: tracked redirect requested.

Gmail API does not provide a definitive delivered webhook. This demo scans the connected mailbox for common DSN/bounce messages. It is best-effort, not a carrier-grade delivery guarantee. Pixel and clicks can be triggered by privacy proxies or automated scanners.
